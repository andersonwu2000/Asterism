- Citing a proved sibling in `patch.lean` requires an explicit `import Problems.Geometry.banach_tarski.proofs.L_<slug>` line — without it the framework only auto-imports registered sub-goals and `lake build` gives `Unknown identifier`; WITH the explicit import, `obtain ⟨…⟩ := <slug> args` works normally (extra conjuncts can be dropped via `_` in the pattern), and this is simpler than inlining the sibling body or re-registering it as a sub-goal.
- Any theorem in the `banach_tarski` namespace whose signature involves `(ρ ^ n : E ≃ᵢ E)` applied to `EuclideanSpace ℝ (Fin 3)` will hit a `(deterministic) timeout at whnf` at the DEFAULT 200k heartbeat limit — prepend `set_option maxHeartbeats 0 in` to the theorem; the correct proof pattern is: `have hnorm : ∀ z, ‖ρ z‖ = ‖z‖ := fun z => by rw [← dist_zero_right, ← dist_zero_right z, ← hρ0]; exact ρ.isometry.dist_eq z 0` then induction with `show ‖ρ ((ρ^n) y)‖ = ‖y‖` (NOT `simp only [pow_succ, IsometryEquiv.coe_mul]` — that triggers the same `whnf` blowup); `IsometryEquiv.coe_mul` and `Function.IsFixedPt.iterate` both exist in Mathlib.
- To produce an infinite-order det-1 rotation `R` whose powers fix no chosen small point (origin-orbit frontier `exists_bounded_injective_origin_orbit`), DON'T build an explicit irrational-angle matrix + prove π-irrationality — take a single generator `R := ψ (FreeGroup.of 0)` of the proved `free_so3_embedding`/s11478 (`ψ : FreeGroup (Fin 2) →* (E ≃ₗᵢ[ℝ] E)`, injective, per-word `hprop : w≠1 → det=1 ∧ ψ w ≠ refl`); then `R^n = ψ ((of 0)^n)` via `(map_pow ψ _ n).symm`, and `hprop` applied to `(of 0)^n ≠ 1` (a `FreeGroup` generator has infinite order — short Builder lemma) gives det-1 ∧ ≠refl for EVERY power, so each `rotation_fixed_set_on_sphere_finite` fixed set on the radius-r sphere is finite and the standard "uncountable sphere minus countably-many finite sets is nonempty" combine (use `¬ (Metric.sphere 0 r).Countable` — `Set.Uncountable` does NOT exist) hands back a point fixed by no positive power.
- The `Equidecomp X G` structure (the S²/ball assembly target) needs only `[SMul G X]` and extends `PartialEquiv X X` (fields `.source`/`.target`/`.toFun`/`.invFun` + the 4 PartialEquiv laws) plus `isDecompOn' : ∃ S : Finset G, Equidecomp.IsDecompOn toFun source S` where `IsDecompOn f A S := ∀ a∈A, ∃ g∈S, f a = g•a`; construct via `Equidecomp.mk`, compose with `Equidecomp.refl`/`Equidecomp.trans` ([Monoid]) and `Equidecomp.symm` ([Group]) — discover all this with `#print Equidecomp` / `#check @Equidecomp.IsDecompOn` via `mcp__lsp__validate_file`, since the `.lake` mathlib source is NOT grep-able from the problem sandbox.
- A Backward sub-goal whose STATEMENT contains a `match` (e.g. `⋃ o : Option _, match o with …`) cannot be cited cross-file (`:= <slug>` or `rw [<slug>]`): each file's `match` syntax elaborates to its own anonymous `match_1`, and on a free scrutinee these constants aren't defeq, so `lake build` reports "Type mismatch" with BOTH types printing identically (the in-`patch` LSP run looks clean because same-file `match` syntax dedupes — the error only surfaces cross-file at build); fix by stating sub-goals match-free (explicit `∪` / `⋃ p`), keeping any `match` step inline in `patch.lean`, and bridging via `rw [Set.iUnion_option]; exact <match_free_slug>` whose `f none ∪ ⋃ a, f (some a)` output iota-reduces against the match-free statement.
- For ANY Hilbert-hotel `Equidecomp` (piecewise `f = ρ` on `T = ⋃ₙ (ρ^n)''D` / id off `T`, `g = ρ.symm` on `T`), the 4 PartialEquiv laws + `IsDecompOn` are ALREADY PROVED as abstract citable bricks `map_source_hilbert`/`map_target_hilbert`/`left_inv_hilbert`/`right_inv_hilbert`/`is_decomp_hilbert` (over abstract `A,D,T,ρ,f,g` with defining-equation hyps `hf:∀x∈T,f x=ρ x` etc.) plus `hotel_shift` (gives `ρ''T=T\D` from pairwise-disjoint orbits) — do NOT re-farm them; `classical`+`set ρ/D/A/T/f/g`, prove `hf/hf'/hg/hg'` by `rw [hf_def]; exact if_pos/if_neg`, cite the bricks inline (needs explicit `import …proofs.L_<brick>`) and assemble `refine ⟨Equidecomp.mk (PartialEquiv.mk f g A (A\D) hms hmt hli hri) hdec, rfl, ?_⟩`, leaving only the genuine concrete sub-goals `T⊆A` / orbit-disjoint / `A\D=target`; CRUCIALLY these bricks need only `T⊆A`,`D⊆T`,`ρ''T=T\D`, NOT full invariance, whereas the bundled `equidecomp_hilbert_hotel` demands `∀x∈A,ρx∈A` which FAILS on non-invariant sources (e.g. the b-block: shifting a `(1,false)`-word by `of 1` gives a `(0,·)`-word ∉ A) — so for non-invariant `A` cite the lower bricks, not `equidecomp_hilbert_hotel`.
- The rotation/freeness bricks (`rotation_fixed_set_on_sphere_finite`, det-1, ≠refl) are typed for `E ≃ₗᵢ[ℝ] E` but the BT goal needs `E ≃ᵢ E`: build the F₂ embedding at the linear level as `ψ : FreeGroup (Fin 2) →* (E ≃ₗᵢ[ℝ] E)` then post-compose with the coercion hom `c : (E ≃ₗᵢ[ℝ] E) →* (E ≃ᵢ E) := { toFun := fun g => g.toIsometryEquiv, map_one' := rfl, map_mul' := fun a b => rfl }` (both `rfl`); `c` is injective via `LinearIsometryEquiv.toIsometryEquiv_injective`, so `φ := c.comp ψ` inherits injectivity by `hcinj.comp hinj`, `φ w 0 = 0` closes by `change (ψ w).toIsometryEquiv 0 = 0; simp`, and the finite-fixed-set goal by `convert (rotation_fixed_set_on_sphere_finite (ψ w) hdet hne) using 2` — never build the generators directly as `≃ᵢ` or the det-1/finite brick becomes inapplicable (this ≃ₗᵢ→≃ᵢ glue is proved as `s11470`, citable).
- Every origin-fixing-isometry argument in the Hilbert-hotel crux (off_axis_mover/s11440, good_angle_avoids_collisions, exists_rotation_shift_disjoint) is FALSE when `0 ∈ D`: `g 0 = 0` puts the origin on the z-axis (and `ρ^n 0 = 0` puts it in `ρ^n''D ∩ D`), so a goal of shape `∃ g, g 0 = 0 ∧ ∀ p∈D, <g p off-axis / moved>` needs `0 ∉ D` — thread `(h0D : 0 ∉ D)` (or `∀ p∈D, p≠0`) down from the sphere fixed-point set through ALL crux bricks; without it the brick is a `return_to_parent`, not provable.
