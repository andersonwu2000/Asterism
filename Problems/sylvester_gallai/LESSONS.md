- For squared-parameter comparison goals of the form `(t_b - t_a)^2 ≤ (t_b - t_f)^2` given same-side (`(t_a-t_f)*(t_b-t_f) ≥ 0`) and closer (`(t_a-t_f)^2 ≤ (t_b-t_f)^2`) hypotheses, `nlinarith [sq_nonneg (t_a-t_f + t_b-t_f), sq_nonneg (t_a-t_f - (t_b-t_f)), sq_nonneg (t_a-t_f), h_same, h_close]` closes the goal without case splits.
- Ratio inequalities `a/b < c/d` between the squared-perpendicular-distance terms cross-multiply with `div_lt_div_iff₀ hb_pos hd_pos` (note the `₀` suffix — plain `div_lt_div_iff` is no longer a Mathlib identifier and errors with `Unknown identifier`); after cross-multiplying, a single `nlinarith` on the full nonlinear system (products of `OldNum²`, `|q-p|²`, `(t_b-t_f)²·D²`) times out at the 200k-heartbeat limit, so `set OldSq := ...` and `set D := ...` to abstract and chain `mul_le_mul_of_nonneg_right` → `lt_of_mul_lt_mul_right` (cancel one `D`) → `mul_lt_mul_of_pos_left` (scale by `OldSq > 0`) so each step is linear in the abstracted symbols.
- Backward strategy `patch.lean` does NOT auto-import this problem's proved Forward lemmas (e.g. `three_reals_same_side`, `collinear_iff_param`, `perp_numerator_sq_param_factor`) — only sub-goal `new_<slug>.lean` files are auto-appended to imports, so referencing a Forward by name in the strategy body fails lake with `Unknown identifier`; either inline the Forward's proof (most are short — `three_reals_same_side` is 4-way `rcases le_or_gt`/`le_total` + `nlinarith`) or shelve the strategy.
- Given parametrisation `hs1 : s.1 = p.1 + t*(q.1-p.1)`, `hs2 : s.2 = p.2 + t*(q.2-p.2)`, translate `s ≠ p` to `t ≠ 0` (and `s ≠ q` to `t ≠ 1`) via `intro ht; apply hsp; ext; · rw [hs1, ht]; ring; · rw [hs2, ht]; ring` — `ext` splits the Prod equality, then `ring` discharges each coord after substituting the parameter value; `simp [hs1, hs2]` does not fire here.
- To convert `hcol : (p.1 - s.1)*(q.2 - s.2) = (p.2 - s.2)*(q.1 - s.1)` into the parametric cross-ratio form `(s.1 - p.1)*(q.2 - p.2) = (s.2 - p.2)*(q.1 - p.1)` needed for `field_simp`/`linarith` parametrization goals, use `linear_combination -hcol` — the two determinant forms are ring-equivalent with coefficient −1, so `nlinarith`/`linarith` won't close it but `linear_combination` does in one step.
- After `unfold Collinear at hcol` and a `rw` substitution, the residual goal is a nonlinear product equation — `linarith` fails; use `linear_combination hcol` (whose `ring` residual check closes it) to extract the consequence.
- To prove `Collinear p q s` from a parametric witness `⟨t, hs1, hs2⟩`, use `unfold Collinear; rw [hs1, hs2]; ring` — substituting the parametric coords turns the determinant into a ring identity.
- To minimize over a `Finset.filter` predicate involving `Collinear` or real arithmetic (no `DecidablePred` instance), add `classical` before the `let S := ... .filter ...` line, then use `Finset.exists_min_image` on `S`; unwrap membership with `Finset.mem_filter` + `Finset.mem_product`.
- For the determinant-based `Collinear` def, `p = q → Collinear p q r` closes by `unfold Collinear; rw [hab]; ring`, so `¬ Collinear p q r → p ≠ q` is always available via `intro hab; apply h; unfold Collinear; rw [hab]; ring`.
