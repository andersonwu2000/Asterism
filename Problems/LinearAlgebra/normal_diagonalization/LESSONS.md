- To split a `Finset.univ` sum into one element plus the rest, use `Finset.sum_erase_add Finset.univ f (Finset.mem_univ i)` (gives `(∑ j ∈ univ.erase i, f j) + f i = ∑ j, f j`); avoid the `Finset.sum_insert` + `Finset.insert_erase` route because `Finset.not_mem_erase` does not exist in this Mathlib and the rewrite leaves a stuck unsolved goal.
- To bridge `(gramSchmidtOrthonormalBasis hcard b).toBasis '' Set.Iic j` to the span lemmas (which speak of `gramSchmidtNormed`/`gramSchmidt`): `Set.image_congr'` + `OrthonormalBasis.coe_toBasis` + `InnerProductSpace.gramSchmidtOrthonormalBasis_apply hcard (hne i)` rewrites it to `gramSchmidtNormed ℂ b '' Set.Iic j`, where the side-condition `hne : gramSchmidtNormed ℂ b i ≠ 0` follows from `gramSchmidtNormed_unit_length i b.linearIndependent` (norm = 1 ⇒ ≠ 0); then `rw [span_gramSchmidtNormed, span_gramSchmidt_Iic]` closes it.
- Gram-Schmidt an ordinary basis to an `OrthonormalBasis` via `InnerProductSpace.gramSchmidtOrthonormalBasis hcard b` (note the `InnerProductSpace.` namespace prefix — bare `gramSchmidtOrthonormalBasis` is an unknown identifier even with `import Mathlib`), where `hcard : Module.finrank ℂ V = Fintype.card (Fin (Module.finrank ℂ V))` is `(Fintype.card_fin _).symm`; initial-segment/flag spans are preserved via `span_gramSchmidt_Iic` + `span_gramSchmidtNormed`.
- Strong induction over `Fin n` rows: Mathlib has no `Fin.strongRecOn`, so generalize to `∀ m : ℕ, ∀ i : Fin n, i.val = m → …` and `induction m using Nat.strong_induction_on`, recovering `j < i → motive j` via `(Fin.lt_def.mp hj).trans_eq hi`; the no-progress guard rejects a sub-goal that just re-states the goal per-row under an `ih` premise (≡ goal modulo induction), so split into non-`IsDiag` sub-goals (e.g. a plain ℝ-sum identity + an abstract vector lemma) and keep the induction inline in patch.lean.
- To prove `(star z * z).re = ‖z‖^2` for `z : ℂ`: chain `Complex.star_def` + `Complex.normSq_eq_conj_mul_self.symm` (giving `star z * z = ↑(normSq z)`) then `Complex.ofReal_re` + `Complex.normSq_eq_norm_sq`; use `Complex.re_sum` to distribute `.re` over `Finset.sum`.
- Adjoint↔conjTranspose in an orthonormal basis: `LinearMap.toMatrix_adjoint e e T : Matrix.conjTranspose (toMatrix e.toBasis e.toBasis T) = toMatrix e.toBasis e.toBasis (adjoint T)`, and `LinearMap.toMatrixOrthonormal e` is a star-algebra equiv so `hT.map (LinearMap.toMatrixOrthonormal e)` transports `Commute (adjoint T) T` to the matrix `Commute` (close with `simpa [LinearMap.toMatrixOrthonormal]`).
- The `ᴴ` conjTranspose glyph parse-fails in this problem's sandbox/LSP; write `Matrix.conjTranspose M` (e.g. in `Commute (Matrix.conjTranspose M) M`).
