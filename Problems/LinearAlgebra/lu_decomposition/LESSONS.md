- When an inductive `BlockTriangular` step yields a subgoal `(fun i => n - 1 - ↑i) j' < (fun i => n - 1 - ↑i) i'` after `apply hBT` but the available hypothesis (from the n+1 level after `simp only [Fin.val_succ]`) has the form `n - (↑j' + 1) < n - (↑i' + 1)`, close with `simp only [Fin.val_succ, Nat.sub_right_comm] at hij ⊢; exact hij` — `Nat.sub_right_comm` equates `n - k - 1` and `n - 1 - k` making the two sides syntactically match; similarly `dsimp only` before `omega` is needed when `apply hBT` for an identity blocking function leaves `(fun i => ↑i) j'` un-beta-reduced.
- For Schur-style identities on `Matrix (Fin (m+1)) (Fin (m+1)) 𝕜` that split off entry `(0,0)`, build a local `e : Fin (m+1) ≃ Fin 1 ⊕ Fin m` via `Fin.cases (Sum.inl 0) Sum.inr` (inv: `Sum.elim (fun _ => 0) Fin.succ`) — `finSumFinEquiv` gives `Fin (1+m)` not `Fin (m+1)`, wrong orientation; then write `M = (Matrix.fromBlocks A B C D).submatrix e e`, get `Invertible A` from `Matrix.invertibleOfDetInvertible` (after `A.det = M 0 0` + `invertibleOfNonzero h00`), and close with `det_submatrix_equiv_self` + `Matrix.det_fromBlocks₁₁`; the residual `⅟A` collapses via `invOf_eq_nonsing_inv` + `inv_def` + `adjugate_fin_one`.
- When bridging a goal over `A.submatrix (Fin.castLE h) (Fin.castLE h)` to one over `A i.succ j.succ`-style entries (e.g. Schur / IH-on-trailing-submatrix), `set M := A.submatrix ...`, prove the abstract statement on `M`, rewrite, then `congr 1` closes the residual matrix equality — `Fin.castLE h i.succ` and `(Fin.castLE h' i).succ` agree on `Fin.val` so `congr` traverses the reindex without manual `simp [Fin.castLE_succ, Matrix.submatrix_apply]`.
- To extract `A 0 0 ≠ 0` from a leading-principal-minor hypothesis `hPM`, instantiate at `k = 1` (proof: `Nat.succ_le_succ (Nat.zero_le n)`) then rewrite with `Matrix.det_fin_one` — the 1×1 submatrix entry reduces definitionally to `A 0 0` so no further `simp` is needed.
- Matrix-method dot-projection on a bare `fun i j => ...` fails (`Invalid field 'submatrix': environment does not contain Function.submatrix`); use `Matrix.submatrix (fun i j => ...)` explicitly or ascribe `(... : Matrix _ _ _)` in sub-goal signatures.
