- To package an LI + spanning family `v` into a `Module.Basis` whose index `Σ s : Fin r, Fin (k s)` may be EMPTY (trivial `W`/`range N`), do NOT use `basisOfLinearIndependentOfCardEqFinrank` — it carries a `[Nonempty ι]` instance arg that fails to synthesize on a generic sigma index; instead use `Module.Basis.mk hLI hsp` with `hLI : LinearIndependent K v` and `hsp : (⊤ : Submodule K W) ≤ Submodule.span K (Set.range v)` (no Nonempty), then transport a chain/Jordan property from `v` to the basis via `Module.Basis.mk_apply hLI hsp idx : (Module.Basis.mk hLI hsp) idx = v idx` (the `Module.` prefix is required when not `open Module`).
- To prove `(T - μ) ↾ maxGenEigenspace T μ` is nilpotent, do NOT build a dimension induction — mathlib has `Module.End.isNilpotent_restrict_maxGenEigenspace_sub_algebraMap T μ h` (needs only `[IsNoetherian]`, supplied by `FiniteDimensional`) giving `IsNilpotent ((T - algebraMap K (End) μ).restrict h)`; bridge to the `T.restrict _ - μ • 1` form via `Algebra.algebraMap_eq_smul_one` (so `algebraMap K (End K V) μ = μ • 1`) plus `ext`/`simp [LinearMap.restrict_apply]` to push `restrict` through the difference.
- Given the generalized top-level lemma carrying `(n : ℕ) (hdim : Module.finrank K W ≤ n)`, run the dimension induction inside it via `induction n generalizing W N hN` — do NOT list `hdim` (it depends on `n` and is auto-generalized; listing it errors `Unnecessary generalizing argument`), and the resulting `ih : ∀ {W'} [insts] (N'), IsNilpotent N' → finrank K W' ≤ m → …` is polymorphic in the carrier so it applies to `range N`/subspaces of a different type.
- To split `∑ i : Σ s : (A ⊕ B), Fin (Sum.elim f g s), h i` into inl/inr parts, use `rw [Fintype.sum_sigma, Fintype.sum_sum_type]` (as `rw`, NOT `simp_rw` — the latter makes no progress); after this rewrite, fiber types like `Fin (Sum.elim f g (Sum.inl t))` stay UN-reduced for `rw [Fin.sum_univ_succ]`, so use `change ∑ j : Fin (f t), ...` to state the reduced type explicitly (`change` bridges definitional equality without proof); for the inr `Fin 1` fiber, `simp [hv_C]` handles `Sum.elim_inr` + `Fin.sum_univ_one` + substitution in one shot.
- To prove `LinearIndependent K v` for the assembled family indexed by `Σ s : ({t // 0 < l t} ⊕ Fin m), Fin (Sum.elim (fun t => l t.1 + 1) (fun _ => 1) s)`, use `Fintype.linearIndependent_iff` (the `Fintype` instance auto-derives) then `intro g hg; rintro ⟨s, j⟩; cases s` — but BEWARE that after casing the sum, the fiber `Sum.elim … (Sum.inl t)` stays UN-reduced, so `(0 : Fin _)` OfNat-synthesis and `Subsingleton (Fin _)` both FAIL on `j`; discharge the bottom index via `have hj : j = (0 : Fin (l ↑t + 1)) := Fin.ext (by simpa using h0)` (annotate the *reduced* type explicitly, defeq bridges to the `Sum.elim` form) and the `Fin 1` complement index via `Fin.fin_one_eq_zero j`, then `rw [hj]`; for the LI itself, apply `N` once to send chain tops/interiors to the range-basis `d` and bottoms/complement to `0`, so `d`-LI kills all index-`≥1` coefficients and `hC2`-disjointness + `cb`/`d` LI kill the rest.
- To enumerate `(μ : K) × Fin (n μ)` (or any `Σ i, Fin (ν i)`) in contiguous Jordan-block order with the same-fiber adjacency `(·:ℕ)+1 = (·:ℕ)` holding *by construction* (NOT by post-hoc permutation, the dead path), use `finSigmaFinEquiv : (Σ i : Fin m, Fin (ν i)) ≃ Fin (∑ i, ν i)` whose coercion `simp`-normalizes to `(∑ x : Fin ↑i, ν (Fin.castLE _ x)) + ↑j` — the offset depends only on the block index `i`, so same-`i` consecutiveness reduces to pure `omega`; first reduce an unordered index type `K` to a `Fin m` base via `Fintype.ofInjective` on `μ ↦ ⟨μ,0⟩` over the finite support `{μ // 0 < n μ}` (the `[Fintype]` binder is what makes the support finite), threading a fiber/value-preserving equiv (`(φ x).1=(φ y).1 ↔ x.1=y.1`, `↑(φ x).2 = ↑x.2`), and if a `LinearOrder` on an arbitrary type is ever needed use `linearOrderOfSTO WellOrderingRel`.
- The disjunctive `hd` chain interface `(N.restrict)(d⟨t,j⟩)=0 ∨ ∃ i, (i:ℕ)+1=(j:ℕ) ∧ (N.restrict)(d⟨t,j⟩)=d⟨t,i⟩` is INSUFFICIENT for any dimension-count goal (`Fintype.card index = finrank K W`, equivalently `finrank(range N ⊓ ker N) = #{t // 0 < l t}`) because the `=0` disjunct is UNCONSTRAINED in `j`, admitting BROKEN chains (some `d⟨t,j⟩` with `j≥1` also in ker) that inflate `finrank(range N ⊓ ker N)` past the chain count — concrete counterexample: `W=K⁴`, `N: e3↦e1, e4↦e2, e1,e2↦0` (so `N²=0`), `p=1, l=fun _=>2`, `d⟨0,0⟩=e1, d⟨0,1⟩=e2`, `C={0}, m=0` satisfies every hypothesis yet `card=3 ≠ 4=finrank`; this is `return_to_parent`, demanding the producer of `hd` restrict the `=0` alternative to `j=0` (proper chains: bottom↦0, every `j≥1`↦predecessor), which alone forces `ker(N.restrict)=span{d⟨t,0⟩ : 0<l t}` and lets rank-nullity close the count — do NOT rebuild the dead `range_inf_ker_finrank`/`s10942` count path.
- The bare predecessor-form `(b, π)` Jordan-basis interface (`hπ : ∀ j, (π j = none ∧ N(b j)=0) ∨ ∃ i, π j = some i ∧ N(b j)=b i`) is INSUFFICIENT for the consecutive-index goal `N(b' j)=0 ∨ ∃ i, (i:ℕ)+1=(j:ℕ) ∧ N(b' j)=b' i` — `hπ` alone admits π-cycles (swap `N(b 0)=b 1, N(b 1)=b 0` is invertible, so the forced `N(b' 0)=0` case fails) and `some`-collisions `π j₁=π j₂=some i` (repairable only by a basis CHANGE, not a reindex), making the goal FALSE; a pure-reindex layout (`b' := b.reindex σ.symm`) needs the parent to also thread `IsNilpotent N` (kills cycles: a π-cycle gives `N^m (b j₀)=b j₀≠0`) AND π-injectivity `∀ j₁ j₂ i, π j₁=some i → π j₂=some i → j₁=j₂` (disjoint chains), so `range_jordan_to_pred_basis` must export both — `return_to_parent`, do not rebuild the dead `chain_permutation_exists`/`s10890` reindex path which dies on exactly this gap.
- To derive `⊤ ≤ Submodule.span K (Set.range v)` from `LinearIndependent K v` + `Fintype.card ι = Module.finrank K W` when `ι` may be EMPTY, the direct lemma `LinearIndependent.span_eq_top_of_card_eq_finrank'` DOES exist (the `'` variant takes `[FiniteDimensional K W]` instead of the unprimed's `[Nonempty ι]`, so empty index is fine) and returns `span K (range v) = ⊤` in one step — flip to `⊤ ≤ span` with `.ge`, cleaner than the `finrank_span_eq_card`→`Submodule.eq_top_of_finrank_eq`→`top_le_iff` chain; conversely `linearIndependent_of_top_le_span_of_card_eq_finrank` goes span+card→LI, so for a `LinearIndependent v ∧ ⊤ ≤ span v` goal prove EITHER conjunct directly plus the count and the bridge yields the other.
- There is NO mathlib lemma for `(hdec.collectedBasis bμ).repr (↑w) ⟨μ,k⟩ = (bμ μ).repr w k` when `w` lives in a single summand (`exact?` fails) — prove it by `Basis.ext` on `bμ μ` comparing the two coordinate functionals `Finsupp.lapply ⟨μ,k⟩ ∘ₗ (collectedBasis bμ).repr.toLinearMap ∘ₗ (submodule).subtype` vs `Finsupp.lapply k ∘ₗ (bμ μ).repr.toLinearMap`, reducing on each basis vector via `collectedBasis_coe` (so `↑(bμ μ k') = collectedBasis ⟨μ,k'⟩`) then `Module.Basis.repr_self_apply` + `Sigma.mk.injEq`; the diagonal entry `diag_block` then closes by `rw [LinearMap.toMatrix_apply, LinearMap.toMatrix_apply, hdec.collectedBasis_coe, LinearMap.restrict_apply]` + this bridge, and the same bridge drives `off_diag`.
