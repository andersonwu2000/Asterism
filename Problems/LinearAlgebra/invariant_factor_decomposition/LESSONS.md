- The injective-reindex split of `prime_power_regroup` (a grid sub-goal exposing `idx : ι → Fin r × Fin s` with cell-match `∀ i, p i^e i = q (idx i).2 ^ c (idx i).1 (idx i).2`, padding `∀ k t, (∀ i, idx i ≠ (k,t)) → c k t = 0`, plus a witness-independent iso sub-goal taking `(q c idx hinj hmatch hpad)`) is UNPROVABLE without `0 < e i`: counterexample ι=Unit, p a=X, e a=0 forces idx a=(k,t) to a cell with `q t^c k t = X^0 = 1`, padding zeroes every other cell of row k, so `∏ₜ q t^c k t = 1 = IsUnit` kills the `∀ k, ¬IsUnit` conjunct (the parent escapes by picking r=0 since e=0 gives trivial summand `K[X]/⊤≅0`, but an injective idx over ALL of ι cannot) — thread `he : ∀ i, 0 < e i` into the grid sub-goal (or grid over `{i // 0 < e i}` and let the iso sub-goal absorb e i=0 summands as trivial `K[X]/⊤`).
- A Backward strategy patch CANNOT cite a proved sibling lemma by name directly (e.g. `crt_directsum_prod_quot`): only the strategy's OWN `new_*.lean` sub-goals get auto-imported, so a cross-sibling reference fails `lake build` with `Unknown identifier` even though it passed the local-`have` structural check — instead re-declare the needed lemma as your own sub-goal (an alpha-equivalent restatement, e.g. abstract `(g : ι → K[X]) (hg : pairwise-coprime) → Nonempty (⨁ K[X]/(g i) ≃ₗ K[X]/(∏ g i))`), and Tier-1 dedupe aliases it onto the existing proved sibling at no extra proof cost; the fibre-wise grid closer is then `refine ⟨DirectSum.congrLinearEquiv (fun k => ?_)⟩; exact (sub_goal (fun t => q t ^ c k t) (fun t t' h => (hcop t t' h).pow)).some`.
- To peel the CRT product-collapse off the noncomputable grid witness, route the recombination iso through the DOUBLE sum: have the witness sub-goal land on `⨁ₖ (⨁ₜ K[X]/(qₜ^cₖₜ))` (each summand an individual prime power, plus the pairwise-coprimality conjunct `∀ t t', t≠t' → IsCoprime (q t) (q t')`), then a witness-independent sub-goal `⨁ₖ⨁ₜ K[X]/(qₜ^cₖₜ) ≃ₗ ⨁ₖ K[X]/(∏ₜ qₜ^cₖₜ)` collapses each row by citing the proved sibling `crt_directsum_prod_quot` (s11568) fibre-wise with `IsCoprime.pow`; the parent closes by `isoA.trans isoB`.
- The shared-witness recombination goal CAN be split without a `Defs.lean` def: state the unified existence sub-goal so it EXPOSES the column grid (`∃ r s (q : Fin s → K[X]) (c : Fin r → Fin s → ℕ), … iso onto ⨁ K[X]/(∏ₜ q t ^ c k t)`) with monotonicity `∀ i j, i ≤ j → ∀ t, c i t ≤ c j t` in place of the divisibility conjunct — then the parent's combinator sets `f k := ∏ₜ q t ^ c k t` and discharges monic via `Polynomial.monic_prod_of_monic`/`Monic.pow`, divisibility via a witness-independent Builder lemma over the abstract grid (`Finset.prod_dvd_prod`+`pow_dvd_pow`), iso directly; this peels the arithmetic conditions off the noncomputable witness cleanly.

- The ideal-arithmetic collapse `⨅ i, Submodule.span K[X] {g i} = Submodule.span K[X] {∏ i, g i}` for pairwise-coprime `g` is a one-liner term proof `Ideal.iInf_span_singleton hg` (mathlib `RingTheory/Ideal/Operations.lean`; needs `hg : ∀ i j, i ≠ j → IsCoprime (g i) (g j)` and `[Fintype ι]`) — `Submodule.span R {x}` is defeq to `Ideal.span {x}` so no conversion is needed; Finset variant is `Ideal.finset_inf_span_singleton`.
