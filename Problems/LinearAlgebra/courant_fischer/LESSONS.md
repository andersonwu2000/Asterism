<!-- LESSONS_BEGIN -->
- For the lower-bound witness `∃ S, finrank S = k+1 ∧ λ_k ≤ sInf (Rayleigh S)`, build S as `Submodule.span ℝ (hT.eigenvectorBasis hn '' {i : Fin n | (i:ℕ) ≤ (k:ℕ)})` — the image-of-set form needs no per-index `Fin`-embedding injectivity boilerplate (unlike the `Module.finBasis` route); peel `λ_k ≤ sInf` with `le_csInf` (forces a `Set.Nonempty` sub-goal + a per-element `λ_k ≤ Rayleigh x`), and keep all three sub-goals standalone by threading `(S : Submodule ℝ E) (hS : S = span …)` as explicit binders, discharging each from patch.lean with `lemma … _ rfl`.
- For the upper-bound `∃ W, finrank W = n−k ∧ ∀ x∈W, x≠0 → Rayleigh x ≤ λ_k`, decouple construction from spectrum by making the spectral lemma W-free: state it as `∀ x, x≠0 → (∀ i:Fin n, i<k → ⟪eigenvectorBasis hn i, x⟫=0) → Rayleigh x ≤ λ_k`, plus a separate construction lemma `∃ W, finrank=n−k ∧ ∀ x∈W, ∀ i<k, ⟪eᵢ,x⟫=0`; this avoids replicating the concrete span W=span{eₖ,…} across sub-goals, and the spectral half reduces to `rayleigh_numerator_eigenbasis` + `eigenvalues_antitone` + Parseval.
- For the lower-bound direction `λ_k ≤ sSup {r | ∃ (k+1)-dim S, r = sInf (Rayleigh S)}`, peel with `le_csSup h_bdd ⟨S, hS, rfl⟩`: this needs (a) a `BddAbove` side-goal on the sSup set (each `sInf ≤ ‖T‖`) and (b) a witness subspace `∃ S, finrank S = k+1 ∧ λ_k ≤ sInf (Rayleigh S)`, closing with `le_trans hge (le_csSup h_bdd ⟨S, hS, rfl⟩)` — factor (a) and (b) as separate sub-goals, mirroring the `csSup_le` peel for the opposite inequality.
- To prove the `BddAbove {r | ∃ S, finrank S=k+1, r = sInf(Rayleigh S)}` side-goal of the `le_csSup` peel, bound each member by the operator norm C: get a nonzero `x∈S` from `finrank S=k+1>0`, then `csInf_le_of_le h_bddbelow ⟨x,hxS,hx0,rfl⟩ h_le` where `h_le : Rayleigh x ≤ C` is the Cauchy–Schwarz UPPER leaf (mirror of the `-C ≤ Rayleigh` lower leaf) and `h_bddbelow` is the same `BddBelow` sub-goal reused; factor the nonzero-witness, h_le, and BddBelow as three standalone sub-goals threading `(S : Submodule ℝ E)` (NOT a concrete span).
- To close the Rayleigh-quotient lower-bound leaf `-C ≤ ⟪Tx,x⟫/‖x‖²` given `hC : ∀ x, ‖Tx‖ ≤ C·‖x‖` and `hx : x ≠ 0`: use `abs_real_inner_le_norm (T x) x` for Cauchy-Schwarz, `neg_abs_le` to get `-|inner| ≤ inner`, then `nlinarith [norm_nonneg x]` to derive `-C·‖x‖² ≤ inner`; finish with `(le_div_iff₀ hpos).mpr` — note `le_div_iff` (without `₀`) does not exist in this Mathlib and will error.
- To prove `BddBelow {q | ∃ x∈S, x≠0, q = ⟪Tx,x⟫/‖x‖²}`, use `-C` as the lower bound where `C` bounds T's operator norm: the operator bound `∃ C, ∀ x, ‖T x‖ ≤ C*‖x‖` is one-liner-citable in finite dim via `⟨‖LinearMap.toContinuousLinearMap T‖, fun x => (LinearMap.toContinuousLinearMap T).le_opNorm x⟩` (no symmetry/hT needed), leaving only a Cauchy–Schwarz+division leaf `-C ≤ ⟪Tx,x⟫/‖x‖²`.
- To bound `sInf (Rayleigh S) ≤ λ_k` from one nonzero witness `x ∈ S`, use `csInf_le h_bdd ⟨x, hxS, hx0, rfl⟩` then `le_trans … hxle`; `csInf_le` forces a separate `BddBelow {q | ∃ x∈S, x≠0, q = ⟪Tx,x⟫/‖x‖²}` side-goal (Rayleigh is bounded below by −‖T‖), so factor it as its own sub-goal rather than re-proving it inline.
- `Submodule.span_induction` now uses a dependent predicate `p : (x : M) → x ∈ span R s → Prop`, so `apply span_induction hu` fails with "failed to elaborate eliminator"; use `refine Submodule.span_induction (p := fun u _ => <your Prop>) ?_ ?_ ?_ ?_ hu` with an explicit non-dependent predicate — add/smul cases take extra `_` for the membership proofs.
- Citing a proved sibling (e.g. `rayleigh_numerator_eigenbasis`) directly in patch.lean fails lake build with `Unknown identifier` — the framework auto-imports ONLY your own `new_*.lean` sub-goals, never sibling/`_strategy_*` modules; to reuse one, re-declare its EXACT statement as your own `new_<slug>.lean` (Tier-1 dedupe aliases it back to the proved sibling, so no re-proving) and cite that slug.
- For the lower-bound per-element leaf `λ_k ≤ ⟪Tx,x⟫/‖x‖²` with x in the top-(k+1) span S, peel the division via `(le_div_iff₀ (pow_pos (norm_pos_iff.mpr hx0) 2)).mpr` to reduce to `λ_k·‖x‖² ≤ ⟪Tx,x⟫`, then decouple into a geometry lemma (`repr x i = 0` for `(k:ℕ)<(i:ℕ)`, from `x∈span(eigenvectorBasis '' {i≤k})`) and a spectral lemma that TAKES that vanishing as a hypothesis (so it is S-free), the spectral half reducing to `rayleigh_numerator_eigenbasis` + `eigenvalues_antitone` + Parseval — the mirror of the upper-bound W-free decoupling.
