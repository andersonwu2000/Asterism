- `rw [Matrix.blockDiagonal'_apply_ne _ k l h]` FAILS (the `_` for the block family leaves `m'`/`n'` metavars unresolved, so `h` gets unified against `dim ≠ dim` not `i ≠ j`); pass the matrix family explicitly — `rw [Matrix.blockDiagonal'_apply_ne (fun i => LinearMap.toMatrix .. (LinearMap.mulLeft K (AdjoinRoot.root (f i)))) k l h]` (the lemma's explicit args after `M` are the *second* Sigma components `k l`, then `h : i ≠ j`).
- For a `toMatrix (DFinsupp.basis pb) _ ((lsmul K[X] (DirectSum..) X).restrictScalars K) = blockDiagonal' …` entry goal: `ext ⟨i,k⟩ ⟨j,l⟩; rw [LinearMap.toMatrix_apply]` then a repr-component lemma `(DFinsupp.basis pb).repr g ⟨i,k⟩ = (pb i).repr (g i) k`, then `by_cases i=j` dispatched by `Matrix.blockDiagonal'_apply_eq` / `Matrix.blockDiagonal'_apply_ne` (the `_eq`/`_ne` variants avoid the `cast` that bare `blockDiagonal'_apply` injects); crucially `rw` on the `(lsmul..X).restrictScalars K` operator FAILS (instance-defeq mismatch, "did not find pattern"), so close leaves with defeq-tolerant `exact congrArg (fun w => (pb i).repr w k) h_sub` and state the off-diagonal sub-lemma at repr-level (`… .repr (op (basis ⟨j,l⟩) i') k' = 0`) so the neg branch is a single `exact`, dodging a `(pb i).repr 0 k = 0` whose inner `0` is defeq-but-not-syntactic.
- On `(LinearMap.lsmul K[X] (DirectSum..) X).restrictScalars K` component goals, `DirectSum.smul_apply` fires ONLY with explicit `(M := fun i => Polynomial K ⧸ Submodule.span (Polynomial K) {f i})` (else instance search binds the `AdjoinRoot` family and fails); beware the seam — `X • m` needs `Submodule.span`'s `Submodule.Quotient.module`, while `AdjoinRoot.root g * m` needs the ring on `AdjoinRoot g = K[X]⧸Ideal.span{g}`, which are defeq but instance-divergent and NOT switchable by ascription (every phrasing of `X • m = root g * m` fails either `HSMul (K[X]) (AdjoinRoot g)` or `HMul (AdjoinRoot g) (_⧸Submodule.span)`), so it is unstatable single-variable — prove inline keeping LHS(`Submodule.span`) and RHS(`AdjoinRoot`) as distinct Eq-bridged terms.
- For a transport/assembly goal (∃ b, toMatrix b b T = blockDiagonal' …), avoid entry-wise grinding by splitting into three: (1) an abstract conjugation lemma `toMatrix (c.map g.symm) (c.map g.symm) T = toMatrix c c S` from hypothesis `∀ v, g (T v) = S (g v)`; (2) the intertwining `g (T v) = S (g v)` with `g = (Module.AEval'.of T).trans (e.restrictScalars K)` and `S = (LinearMap.lsmul (K[X]) _ Polynomial.X).restrictScalars K`, via `Module.AEval'.X_smul_of` + `e`'s K[X]-linearity; (3) `toMatrix c c S = blockDiagonal' …` on `c = DFinsupp.basis (powerBasis'ᵢ)` alone (no T/e) — `set g/c/S with hg/hc/hS`, cite each by `rw [hg/hc/hS]` to dodge fvar-vs-expr mismatch.

- For root assembly (∃ b, toMatrix b b T = blockDiagonal' companionMatrix), build `b` as `(DFinsupp.basis (fun i => (AdjoinRoot.powerBasis' (hmonic i)).basis)).map (e.restrictScalars K).symm |>.map (AEval'.of T).symm`; for `DFinsupp.basis pb` component goals the repr formula `(pb i).repr (x i) k = (DFinsupp.basis pb).repr x ⟨i,k⟩` is `rfl`, and `(DFinsupp.basis pb).repr ((DFinsupp.basis pb) ⟨j,l⟩) = Finsupp.single ⟨j,l⟩ 1` is `LinearEquiv.apply_symm_apply _ _`; off-diagonal zeros close via `apply (pb i').repr.injective; ext k'; rw [show ... = ... from rfl]; rw [LinearEquiv.apply_symm_apply _ _]; exact Finsupp.single_eq_of_ne (fun heq => h (Sigma.mk.inj heq).1)` — no DFinsupp.basis unfolding needed.
- To prove a specific `p %ₘ f = r` identity (monic f), use `Polynomial.div_modByMonic_unique q r hf ⟨by ring, hdeg⟩` — supply quotient and remainder explicitly; the degree bound `degree r < degree f` follows from `Polynomial.degree_sub_lt` when `p` and `f` share degree and leadingCoeff (use `Polynomial.degree_X_pow` + `Polynomial.leadingCoeff_X_pow` + `Monic.leadingCoeff`; annotate `Polynomial.X (R := K)` to fix stuck Semiring metavariables).
- The "unstatable" X-smul↔root-mul seam (bullet 3) on a diagonal component goal `X • ((DFinsupp.basis pb) ⟨j,l⟩) j = root (f j) * (pb j) l` IS closable: after `rw [LinearMap.restrictScalars_apply, LinearMap.lsmul_apply]; rw [DirectSum.smul_apply (M := fun i => Polynomial K ⧸ Submodule.span (Polynomial K) {f i}) Polynomial.X _ j]`, the LHS `X •[Submodule.Quotient]` is DEFEQ to `root (f j) * ·`, so `change AdjoinRoot.root (f j) * ((DFinsupp.basis pb) ⟨j,l⟩ j) = root (f j) * (pb j) l` retypes it (a plain `rw [hcomp]` FAILS — "did not find pattern" on the smul'd occurrence), then `exact congrArg (fun w => AdjoinRoot.root (f j) * w) hcomp` where `hcomp : (DFinsupp.basis pb) ⟨j,l⟩ j = (pb j) l` is a pure `DFinsupp.basis` eval (no X-action, no seam) safely delegated as a Builder sub-goal.
