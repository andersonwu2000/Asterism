- To recursively build `W : ℕ → Submodule K V` whose step needs an invariant of `W i` (e.g. T-invariance to apply an extension existential), define a sigma-packaged carrier `WP : ℕ → {U : Submodule K V // <invariant U>}` via `Nat.rec` so `Classical.choose (h_ext (WP i).1 (WP i).2)` threads the invariant through each step, then extract `fun i => (WP i).1`; the chain / rank conjuncts unpack directly from `Classical.choose_spec`. Note `Submodule.mem_bot` takes `K` explicitly, so write `(Submodule.mem_bot K).1 hv`, not `Submodule.mem_bot.mp hv`.
- `Submodule.eq_of_le_of_finrank_eq {U W : Submodule K V} (h : U ≤ W) (hf : finrank K U = finrank K W) : U = W` closes any "two submodules with containment + equal finrank must be equal" goal; to prove `W ≤ U` from `U ≤ W` and equal finrank, use `(Submodule.eq_of_le_of_finrank_eq hle hf).symm.le`.
- To prove `Nontrivial (V ⧸ U)` from a finrank gap, use `Submodule.finrank_quotient_add_finrank U` (gives `finrank K (V ⧸ U) + finrank K U = finrank K V`) with `omega` to get `0 < finrank K (V ⧸ U)`, then close with `Module.nontrivial_of_finrank_pos`; also note `finrank_top K V` (not `Submodule.finrank_top`) is the correct lemma name for `finrank K (⊤ : Submodule K V) = finrank K V`.
- `Submodule.Quotient.mk_eq_zero` does not exist in this Mathlib; to convert `U.mkQ x = 0 ↔ x ∈ U` use `rw [← LinearMap.mem_ker, Submodule.ker_mkQ]`, and to prove `U.mkQ v = 0` from `v ∈ U` use `simp [hv]` (simp knows the quotient-map-zero fact).
- To package a spanning family `v : Fin n → V` as a `Basis`, use `linearIndependent_iff_card_le_finrank_span` (needs `OrzechProperty`, satisfied by `Field`) to get LI from `n ≤ Set.finrank K (Set.range v)` where `Set.finrank K s` unfolds definitionally to `Module.finrank K (Submodule.span K s)`; rewrite with `finrank_top` once the span equals `⊤`, then pass `hspan_eq.symm.le` to `Basis.mk` (it needs `⊤ ≤ span`, not `span = ⊤`), and recover `b i = v i` via `Basis.mk_apply`.
- `SetLike.exists_of_lt {h : U < W} : ∃ x ∈ W, x ∉ U` is the direct one-liner for any "find a vector in W outside U" goal once you have a strict submodule inclusion; combine `lt_of_le_of_ne hU hne` to build the strict inclusion from `U ≤ W` + a rank-mismatch argument.
- `Submodule.finrank_sup_span_singleton [Module.Finite K V] {p : Submodule K V} {v : V} (hv : v ∉ p) : finrank K (p ⊔ span K {v} : Submodule K V) = finrank K p + 1` closes rank-increment goals directly; `FiniteDimensional` satisfies `Module.Finite`, so `exact Submodule.finrank_sup_span_singleton hv` suffices.
- To decompose `w ∈ U ⊔ K∙v` into `u + c•v`, use `Submodule.mem_sup.mp` (yields `w = u + s` with `u ∈ U`, `s ∈ K∙v`) then `Submodule.mem_span_singleton.mp` (yields `c : K` with `s = c•v`); this two-step pattern applies to every T-invariance or membership goal on `U ⊔ Submodule.span K {v}`.
- `Module.finrank K (U ⊔ Submodule.span K {v})` fails to elaborate with `failed to synthesize Max (Type u_2)` because Lean tries `⊔` at Type level before inserting the `↥` coercion; annotate as `Module.finrank K ((U ⊔ Submodule.span K {v} : Submodule K V))` whenever stating rank goals involving sup of submodules.
- `Basis.repr_support_subset_of_mem_span (s : Set ι) (hm : m ∈ span R (b '' s)) : (b.repr m).support ⊆ s` is the direct bridge from span-membership to zero matrix entries; combine with `Finsupp.mem_support_iff` + `not_not` to close `(b.repr v) i = 0` goals when `i ∉ s`.
