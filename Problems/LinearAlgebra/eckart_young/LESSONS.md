- For the Eckart–Young lower bound `σ_k ∈ lowerBounds {‖T-S‖ : rank S ≤ k}`: unfold with `intro r hr; obtain ⟨S, hrank, hr⟩ := hr; subst hr` (goal `σ_k ≤ ‖T-S‖`), then `by_cases hk : k < finrank 𝕜 E` — degenerate branch closes by `rw [T.singularValues_of_finrank_le (not_lt.mp hk)]; exact norm_nonneg _` (σ_k=0 when finrank E ≤ k); main branch needs a kernel-witness sub-goal `∃ x ≠ 0, S x = 0 ∧ σ_k‖x‖ ≤ ‖T x‖` (built from rank-nullity + the proved sibling `subspace_inter_nonzero_finrank_rclike` on the top-(k+1) right-singular span ∩ ker S), then lift to the operator norm via the abstract leaf `c‖x‖ ≤ ‖A x‖ → c ≤ ‖A.toContinuousLinearMap‖` (`le_opNorm` + `le_of_mul_le_mul_right`), using `(T-S) x = T x` (since `S x = 0`, via `rw [LinearMap.sub_apply, hSx, sub_zero]`).
- To PROVE the diagonalization identity `re⟪T x,x⟫ = ∑ i, hT.eigenvalues hn i * ‖inner 𝕜 (hT.eigenvectorBasis hn i) x‖²` directly (clean leaf, no sub-goals): `rw [← OrthonormalBasis.sum_inner_mul_inner (hT.eigenvectorBasis hn) (T x) x, map_sum]; apply Finset.sum_congr rfl; intro i _; rw [hT x (hT.eigenvectorBasis hn i), hT.apply_eigenvectorBasis hn i, inner_smul_right, ← inner_conj_symm, mul_assoc, RCLike.conj_mul, ← RCLike.ofReal_pow, ← RCLike.ofReal_mul, RCLike.ofReal_re]` — key moves: `hT x y` rewrites `⟪Tx,y⟫=⟪x,Ty⟫`, `inner_smul_right` pulls the eigenvalue cast out, `← inner_conj_symm`+`RCLike.conj_mul` give `conj z * z = ‖z‖²`, and `ofReal_pow/ofReal_mul/ofReal_re` collapse the real summand.
- To bound the Rayleigh quotient `re⟪T x, x⟫ ≤ c‖x‖²` for symmetric `T` (e.g. `A†A`, `c=σ₀²`), diagonalize in `hT.eigenvectorBasis hn`: sub-goal 1 is `re⟪Tx,x⟫ = ∑ i, hT.eigenvalues hn i * ‖inner 𝕜 (hT.eigenvectorBasis hn i) x‖²`, sub-goal 2 is `hT.eigenvalues hn i ≤ c` (via `eigenvalues_antitone hn (Fin.zero_le i)` + `sq_singularValues_fin` for `c=σ₀²`), then collapse `∑ ‖inner 𝕜 (b i) x‖² = ‖x‖²` inline with `OrthonormalBasis.sum_sq_norm_inner_right` (NOT a sub-goal) and combine: `rw [h_rayleigh, ← b.sum_sq_norm_inner_right x, Finset.mul_sum]; exact Finset.sum_le_sum fun i _ => mul_le_mul_of_nonneg_right (h_eig_le i) (sq_nonneg _)`.
- To extract a unit eigenvector of A†A with eigenvalue σ₀², use `hasEigenvalue_adjoint_comp_self_sq_singularValues h` (requires `h : 0 < finrank 𝕜 E`) then `.exists_hasEigenvector`; normalize with `(‖v₀‖⁻¹ : 𝕜) • v₀` and close the unit-norm goal via `norm_smul → norm_inv → RCLike.norm_ofReal → abs_of_nonneg (norm_nonneg _) → inv_mul_cancel₀`; `norm_inv` is needed because `norm_smul` leaves `‖(↑‖v₀‖)⁻¹‖` (cast-then-invert), not `‖↑(‖v₀‖⁻¹)‖`.
- To prove `‖A v‖ = s` from a unit-vector eigenvector equation `(A†∘A) v = (↑(s^2):𝕜) • v`, use `rw [norm_sq_eq_re_inner, ← adjoint_inner_left, heig, inner_smul_left, RCLike.conj_ofReal, inner_self_eq_norm_sq_to_K, hv]` to reduce `‖A v‖^2 = s^2`, then `nlinarith` with `norm_nonneg`; the key is `RCLike.conj_ofReal` (clears the conjugate of a ℝ→𝕜 cast) and `inner_self_eq_norm_sq_to_K` (the 𝕜-typed form, not the `re`-form).
- To prove `‖x - K.starProjection x‖ ≤ ‖x‖`: do NOT use `Kᗮ.norm_starProjection_apply_le` — it heartbeat-timeouts on `Kᗮ.HasOrthogonalProjection` instance synthesis; instead `have hpy := K.orthogonalProjectionFn_norm_sq x` (Pythagorean identity), `simp only [Submodule.orthogonalProjectionFn_eq, Submodule.coe_orthogonalProjection_apply] at hpy` to bridge the coercion gap between `↑(K.orthogonalProjection x)` and `K.starProjection x`, then `nlinarith [norm_nonneg x, norm_nonneg (x - K.starProjection x), norm_nonneg (K.starProjection x)]`.
- This problem's `Defs.lean` imports only Mathlib, so `Library.LinearAlgebra.SVD.*` decls are NOT in scope in patch/sub-goal files (no imports allowed) — rebuild SVD facts from Mathlib directly: the top right-singular vector is `A.isSymmetric_adjoint_comp_self.eigenvectorBasis rfl ⟨0,h⟩` and `apply_eigenvectorBasis` + `sq_singularValues_fin rfl` give `A†A v = σ₀² • v`.
- For a pointwise spectral bound `‖A x‖ ≤ σ₀ * ‖x‖`, reduce to the squared form `‖A x‖^2 ≤ σ₀^2 * ‖x‖^2` (the real eigenvalue/Rayleigh content, `σ₀² = top eigenvalue of A†A`) as a sub-goal, then close the original via `rw [mul_pow]` into `(σ₀*‖x‖)^2` and `le_of_sq_le_sq key (mul_nonneg hσ hx)` (both sides nonneg).
- For `c ≤ ‖A.toContinuousLinearMap‖` from `c * ‖x‖ ≤ ‖A x‖` with `x ≠ 0`: get `‖A x‖ ≤ ‖A.toContinuousLinearMap‖ * ‖x‖` via `A.toContinuousLinearMap.le_opNorm x` with `simp only [LinearMap.coe_toContinuousLinearMap']` to bridge `A.toContinuousLinearMap x = A x`, then `le_of_mul_le_mul_right (hbound.trans hle) (norm_pos_iff.mpr hx)`; the simp lemma name `coe_toContinuousLinearMap'` (not `apply`) is non-obvious.
- For the Eckart–Young MEMBERSHIP/truncation-projection direction (`∃ P, finrank(range P) ≤ k ∧ ∀ x, ‖Tx-T(Px)‖ ≤ σ_k‖x‖`), use `P = K.starProjection.toLinearMap` with `K` = span of the top-k eigenvectors of `T†T`; CRITICALLY abstract `K` first via `obtain ⟨K, hKfr, hKbound⟩ : ∃ K, finrank 𝕜 K ≤ k ∧ ∀ y ∈ Kᗮ, ‖T y‖ ≤ σ_k‖y‖` because inlining the span with `set K := …eigenvectorBasis…` makes instance synthesis `whnf`/`isDefEq` heartbeat-timeout — once `K` is opaque, `LinearMap.range K.starProjection.toLinearMap = K` is `Submodule.range_starProjection`, `x - K.starProjection x ∈ Kᗮ` is `sub_starProjection_mem_orthogonal`, the contraction `‖x - K.starProjection x‖ ≤ ‖x‖` must be its OWN leaf (also times out inline), `finrank K ≤ k` is `finrank_range_le_card` + `Fintype.card_fin`, and the degenerate `¬k<finrank E` branch is `P = LinearMap.id` (`range_id`+`finrank_top`, residual 0).
