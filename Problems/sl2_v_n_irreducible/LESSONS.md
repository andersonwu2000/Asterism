- `HasPrimitiveVectorWith.pow_toEnd_f_eq_zero_of_eq_nat` and `pow_toEnd_f_ne_zero_of_eq_nat` require `[IsDomain R] [IsNoetherian R M] [IsTorsionFree R M]`; in this problem's context (`[Field R] [CharZero R] [Module.Finite R M]`) all three are automatically inferred via Mathlib instances, so `haveI : X := inferInstance` is sufficient — no manual construction needed.
- When a theorem carries irrelevant hypotheses (e.g., `W`, `c`, guard conditions) before the induction variable `j`, direct induction gives an IH burdened with those guards; use `suffices hkey : ∀ k, <core equation> from hkey j` to strip them first, then induct on `k` with a clean IH.
- To extend a kill `(T^k) x = 0` to `(T^j) x = 0` for `j ≥ k` (e.g., `T = LieModule.toEnd R L M e`), introduce `hjeq : j = (j - k) + k := by omega` then `rw [hjeq, pow_add, Module.End.mul_apply, hkill, map_zero]` — `pow_add` + `Module.End.mul_apply` is the canonical bridge from `T^(a+b) x` to `T^a (T^b x)`.
- When using `Finset.filter` with a predicate on an abstract `Field R`-valued function (e.g., `fun i => c i ≠ 0`), Lean cannot synthesize `DecidablePred` — add `classical` at the start of the tactic block (or `open Classical`) to resolve it; `Finset.max'` and related API then work without further changes.
- To show `x ∈ LieSubmodule.lieSpan R L s ⊆ (N : Submodule R M)` when `N` is not itself a `LieSubmodule`, use `induction hx using LieSubmodule.lieSpan_induction with | mem | zero | add | smul | lie` — `Submodule.{zero,add,smul}_mem` close 3 of 5 cases automatically, leaving only the `s ⊆ N` base and bracket-closure as real content; prefer this over `refine LieSubmodule.lieSpan_induction (p := ...) ?_*` whose positional slots misalign easily.
- To unpack `x ∈ Submodule.span R ((fun i => g i) '' (s : Finset α))` into `∃ c : α → R, ∑ i ∈ s, c i • g i = x`, use `rw [Submodule.mem_span_image_finset_iff_exists_fun'] at h` (the prime variant gives `α → R` coefficients directly, avoiding subtype unwrapping).
- For `Submodule.span R` of a `Finset.range n`-indexed family on the ambient module `M`, prefer `Set.image` over the coerced Finset — `(fun i => …) '' (Finset.range n : Set ℕ)` — instead of `Finset.image`, since `Finset.image` demands `DecidableEq M` which is not available in this problem's typeclass context.
- To unfold `(LieModule.toEnd R L M e ^ (k+1)) w` in an induction succ case, use `rw [pow_succ', Module.End.mul_apply, LieModule.toEnd_apply_apply]`; then bridge from the resulting L-bracket `⁅e, _⁆` to a `t.toLieSubalgebra R`-bracket with `change` (safe since `LieSubalgebra.coe_bracket_of_module` is `rfl`), and close `LieSubmodule` membership with `W.lie_mem`.
- Iterated e/f actions on `M` are best written `(LieModule.toEnd R L M e) ^ k` (resp. `f`) — matches Mathlib's `lie_e_pow_succ_toEnd_f` / `lie_h_pow_toEnd_f` Sl2 API; `LieSubalgebra.toEnd_mk` gives rfl-eq with the `t.toLieSubalgebra`-action, so `LieSubmodule W` closure carries over directly.
- To extract a nonzero witness from a non-bottom `LieSubmodule W`, use `rw [ne_eq, LieSubmodule.eq_bot_iff] at h; push Not at h` — `Submodule.ne_bot_iff` does not apply directly to `LieSubmodule`.
