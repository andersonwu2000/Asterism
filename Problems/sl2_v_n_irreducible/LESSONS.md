- `HasPrimitiveVectorWith.pow_toEnd_f_eq_zero_of_eq_nat` (and `pow_toEnd_f_ne_zero_of_eq_nat`) require `[IsDomain R][IsNoetherian R M][IsTorsionFree R M]`; under `[Field R][CharZero R][Module.Finite R M]` all three synthesize automatically via existing instances (Field→IsDomain, Module.Finite over Field→IsNoetherian, DivisionSemiring→IsTorsionFree) — no `haveI` boilerplate needed.
- For the closed-form induction step `((toEnd e)^(k+1)) (((toEnd f)^(k+1)) v) = scalar • v`, use `rw [pow_succ, Module.End.mul_apply, LieModule.toEnd_apply_apply, hv.lie_e_pow_succ_toEnd_f k, map_smul, ih_k, smul_smul, Finset.prod_range_succ, mul_comm]`: `pow_succ` (right-peel `a^(n+1) = a^n * a`) lands the descent on `⁅e, fᵏ⁺¹·v⁆` inside `(toEnd e)^k` so `map_smul` can pull the scalar out and `ih_k` fires — `pow_succ'` (left-peel) wraps the bracket around `(toEnd e)^k (...)` and the descent fails to match.
- To reduce `⁅y, m⁆ ∈ S` for `y : t.toLieSubalgebra R` to the three basis cases `⁅e,m⁆`, `⁅f,m⁆`, `⁅h,m⁆`: `obtain ⟨c₁,c₂,c₃,hy⟩ := (IsSl2Triple.mem_toLieSubalgebra_iff (R := R)).mp y.2` gives `↑y = c₁•e + c₂•f + c₃•⁅e,f⁆` (NOT `c₃•h` — rewrite via `t.lie_e_f`), then `change ⁅(y:L), m⁆ ∈ _` descends to the L-level bracket (rfl via `LieSubalgebra.coe_bracket_of_module`), and `rw [hy, t.lie_e_f, add_lie, add_lie, smul_lie, smul_lie, smul_lie]` reduces to `Submodule.add_mem`/`smul_mem` on the three sub-claims.
- To prove `∏ i ∈ Finset.range m, f i ≠ 0` in a CharZero field, use `rw [Finset.prod_ne_zero_iff]` (not `Finset.prod_ne_zero` — that constant does not exist); for factors of the form `(n : R) - i`, close with `rw [sub_ne_zero]; exact_mod_cast (Nat.ne_of_lt hin).symm` — the `.symm` is required because `Nat.ne_of_lt` gives `i ≠ n` but `sub_ne_zero` needs `n ≠ i`.
- To prove `(toEnd R L M e)^j ((toEnd R L M f)^i v) = 0` for `i < j`, induct on `i` (not `j`): base uses `hv.lie_e` (e·v = 0, cleared by `simp [toEnd_apply_apply, hv.lie_e]`); step rewrites via `rw [LieModule.toEnd_apply_apply]; exact hv.lie_e_pow_succ_toEnd_f i'` to get `c • f^i' v`, then `rw [key, map_smul]; simp [ih j' ...]` closes with `smul_zero`; note the lemma coefficient is `(↑i' + 1) * (↑n - ↑i')` (not `↑(i'+1) * ...`), so match that form exactly in the `have key` type.
- To prove `⁅y, m⁆ ∈ Submodule.span R (Set.range g)` for arbitrary `m` in that span, `induction hm using Submodule.span_induction` with cases `| mem x hx => obtain ⟨k, rfl⟩ := hx; <sub-lemma>`, `| zero => simp`, `| add _ _ _ _ ih1 ih2 => rw [lie_add]; exact Submodule.add_mem _ ih1 ih2`, `| smul a _ _ ih => rw [lie_smul]; exact Submodule.smul_mem _ a ih`; collapses span-closure under a Lie action to a single generator-only sub-goal.
- To show `LieSubmodule.lieSpan R L {v} ≤ P` where `P` is an R-Submodule, package `P` as a `LieSubmodule` via the anonymous constructor `{ toSubmodule := P, lie_mem := <closure> }`, then apply `LieSubmodule.lieSpan_le.mpr (Set.singleton_subset_iff.mpr hv_mem)`; cleaner than `lieSpan_induction` and isolates the only real content (Lie-bracket closure of `P`) as a single sub-lemma.
- For `LieSubmodule W` closure under `(LieModule.toEnd R L M e)^k`, use `simp [LieModule.toEnd_apply_apply]` to rewrite `toEnd R L M e m` to `⁅⟨e, he_mem⟩, m⁆`, then `W.lie_mem ih` closes the goal — the subalgebra element and module element are both implicit in `lie_mem`, only the membership proof is explicit; `LieSubalgebra.toEnd_mk`/`toEnd_eq` are not needed for this pattern.
- `LieSubalgebra.toEnd_mk` / `LieSubalgebra.toEnd_eq` bridge `LieModule.toEnd R K M ⟨x, hx⟩ = LieModule.toEnd R L M x` for `K : LieSubalgebra R L`; needed to align iterated-action closure on `LieSubmodule R (t.toLieSubalgebra R) M` (whose `lie_mem` is over the sub-algebra) with iterations stated as `(LieModule.toEnd R L M e) ^ k`.
- For `LieSubmodule W ≠ ⊥ → ∃ w ∈ W, w ≠ 0`, use `by_contra h; push Not at h; apply hWne; ext x; simp only [LieSubmodule.mem_bot]`; the `Submodule.ne_bot_iff` route via `LieSubmodule.toSubmodule_eq_bot.mp` fails with "Unknown constant" — dot-notation `.mp` on those lemma names is broken in this Mathlib version.
