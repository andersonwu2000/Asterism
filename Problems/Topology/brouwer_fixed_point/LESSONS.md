<!-- LESSONS_BEGIN -->
- To prove `‖x + s • w‖^2 = ‖x‖^2 + 2*s*⟨x,w⟩ + s^2*‖w‖^2` in a real inner-product space, use `rw [norm_add_sq_real, inner_smul_right, norm_smul]; ring_nf; rw [Real.norm_eq_abs, sq_abs]` — `sq_abs` (converting `|s|^2 → s^2`) is the non-obvious final step after `ring_nf` stalls with a remaining `‖s‖^2` term.
- To prove `ContractibleSpace ↥(Metric.closedBall 0 1)` (or any convex set containing `0`), use `(convex_closedBall _ _).starConvex hmem |>.contractibleSpace ⟨_, hmem⟩` — note `StarConvex.contractibleSpace` takes `Set.Nonempty s` (pass `⟨0, hmem⟩`), NOT the membership proof `hmem : 0 ∈ s` directly; the type-mismatch is easy to trip on since `StarConvex` already carries the basepoint.
- To transfer `IsCompact` across a homeomorphism `e : S ≃ₜ T` you built, use `rw [isCompact_iff_compactSpace]; have := isCompact_iff_compactSpace.mp hcomp; exact e.compactSpace` — `Homeomorph.compactSpace` is the instance method that propagates `CompactSpace` across `≃ₜ`; also, `fun_prop` closes continuity of subtype-map compositions like `fun ⟨x, hx⟩ => ⟨⟨x, h hx⟩, hx⟩` automatically, and `Convex.linear_preimage V.subtype` handles convexity of the preimage under the submodule inclusion.
- To prove `gaugeRescaleHomeomorph s t ... '' s = t`, no ready-made image lemma exists; unfold the coercion with `simp [gaugeRescaleHomeomorph, gaugeRescaleEquiv]`, close the forward direction with `gauge_gaugeRescale` (gives `gauge t (gaugeRescale s t y) = gauge s y`), and the backward direction with `gaugeRescale_gaugeRescale hT_abs hT_bdd x` + `gaugeRescale_self`; for closed convex T, `gauge T y ≤ 1 → y ∈ T` follows by showing y ∈ closure (interior T) via the sequence `t • y` (t < 1, `gauge T (t•y) = t * gauge T y < 1`) converging to y.
- To prove `affineSpan ℝ T = ⊤` from `Submodule.span ℝ T = ⊤` and `0 ∈ T`: use `direction_affineSpan` (top-level, NOT `AffineSubspace.direction_affineSpan`) to rewrite direction as `vectorSpan`, prove `vectorSpan = span` via `vsub_mem_vectorSpan ℝ hv h0` + `simpa`, then close each membership via `vadd_mem_iff_mem_direction x hmem0` writing `x = x +ᵥ (0 : V)`.
- To show a convex set `T` in a finite-dim real normed space has nonempty interior, use `Convex.interior_nonempty_iff_affineSpan_eq_top hTconv` and reduce to `affineSpan ℝ T = ⊤`; cheaper than constructing an explicit simplex/ball inside `T`.
- When working with `e : W ≃ₗᵢ[ℝ] V` set images, Lean does NOT unify `⇑e.toHomeomorph`, `⇑(e.toLinearEquiv.toLinearMap)`, and `⇑e` without explicit simp lemmas; use `LinearIsometryEquiv.coe_toHomeomorph` to reconcile the homeomorph coercion and `LinearEquiv.coe_coe, LinearIsometryEquiv.coe_toLinearEquiv` to reconcile the linear-map coercion.
- To convert an ambient-space homeomorphism `e : E ≃ₜ E` with `e '' S = T` into a subtype homeomorphism `S ≃ₜ T`, compose `Homeomorph.image e S : S ≃ₜ e '' S` with `Homeomorph.setCongr (h : e '' S = T)`; for the convex-body-to-closed-ball case, the witness `e` is `gaugeRescaleHomeomorph` from `Mathlib.Analysis.Convex.GaugeRescale` (needs `Convex ℝ s`, `s ∈ 𝓝 0`, `Bornology.IsVonNBounded ℝ s` for both sets).
- To move a set from a finite-dim ℝ-inner-product space `W` to `EuclideanSpace ℝ (Fin n)`, use `(stdOrthonormalBasis ℝ W).repr` (a `W ≃ₗᵢ[ℝ] EuclideanSpace ℝ (Fin (Module.finrank ℝ W))`); its underlying homeomorphism preserves compactness/convexity/interior and gives `T ≃ₜ e '' T` for free.
- For translating a set by vector `v` while preserving convexity, use `e := Homeomorph.addLeft v` (maps `x ↦ v + x`), NOT `addRight`; `Convex.translate hs v` gives convexity of `e '' s` directly since it uses left-addition, and `e.image S : ↑S ≃ₜ ↑(e '' S)` gives the subtype homeomorphism for free.
